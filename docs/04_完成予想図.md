# デイリータスク管理アプリ 完成予想図 Ver.1.0

作成日：2026-11-16
完成時に「こうなっている」姿を定める文書。動作の詳細は「03_仕様書.md」が正。画面イメージは参考ではなく、完成時の表示基準として扱う。

**画像版モック**：本書の画面構成をもとに、実際のアプリ画面風モック（全6画面、Ashiato案Aと同じギャラリー形式）をSpace「デイリータスク管理アプリ 完成予想図」に作成した（2026-11-16）。表示内容の基準は引き続き本書とする。

**モックの数値・細部について（2026-11-16追記）**：画像モックの数値（ストリーク日数など）と細部の配置は仮表示であり、仕様の正解ではない。例えばゲーム詳細モックの連続日数はカレンダーの達成表示とは連動していないし、「今日」画面のゲーム追加ボタンがタブバーに重なって見えるのはモック側の表現である。実装では仕様書と本書の構成に沿った配置・実データから計算した数値を使う。画像だけにあり仕様書にない要素（月間達成率、統計の平均値など）は、正式採用を本人が決定するまで実装対象外とする。

## 1. 完成時の姿（全体像）
- アプリを開くと、その瞬間に「今日あと何をやればいいか」が全ゲーム分、一画面で分かる
- ゲームごとにリセット時刻が違っても、表示も通知もウィジェットも同じ「ゲーム日」で揃っている
- チェックする操作はタップ1回だけ。記録は自動で残り、ストリークと達成率で継続が見える
- リセット前には、残っているゲームだけ通知が来る

## 2. 画面構成
タブは3つ：**今日 / 統計 / 設定**。ゲームの管理は「今日」画面から各ゲームの詳細へ進んで行う。

### 2.1 今日（ホーム）
```text
┌─────────────────────────────┐
│ 11月17日(火)      残り合計 5件 │
├─────────────────────────────┤
│ ゲームA        リセットまで 3:12 │
│ ☑ ログイン                     │
│ ☐ デイリークエスト 3つ          │
│ ☐ 週間ボス                     │
│   連続 12日 🔥                  │
├─────────────────────────────┤
│ ゲームB        リセットまで 8:40 │
│ ☐ ログイン                     │
│ ☐ デイリー素材集め              │
├─────────────────────────────┤
│ ✓ ゲームC（全て完了）           │
├─────────────────────────────┤
│ ＋ ゲームを追加                 │
└─────────────────────────────┘
```
- 残りがあるゲームを上に、全完了のゲームは畳んで下に
- 各ゲームの見出し：名前、リセットまでの残り時間、残り件数
- デイリーとウィークリーは見出しやラベルで区別できるように並べる

### 2.4 設定
- 通知：オン／オフ、リードタイム（15分／30分／60分／120分から選択）
- 通知権限の状態表示と案内

### 2.5 ウィジェット
```text
 small            medium
┌──────────┐   ┌──────────────────┐
│ 今日の残り │   │ 今日の残り 5件     │
│   5件     │   │ ゲームA あと3      │
│ ゲームA…  │   │ ゲームB あと2      │
└──────────┘   │ ゲームC ✓完了      │
               └──────────────────┘
```

## 3. 操作の流れ（完成時にできること）
1. ゲームを登録する（名前とリセット時刻を入れる）
2. そのゲームのデイリー／ウィークリータスクを登録する
3. 毎日、遊び終わったタスクからチェックしていく
4. リセットを跨ぐと自動で新しい1日分になる
5. うっかり残していると、リセット前に通知が来る
6. 週末に統計で達成率を眺める

## 4. デザイン方針
- 標準のSwiftUIコンポーネントを基本とし、片手で素早くチェックできることを優先する
- 色は達成状態の区別（完了／未完了／一部）にだけ意味を持たせ、装飾は控えめにする
- ダークモード対応（システム設定に従う）
- 文字サイズはDynamic Typeに従う
