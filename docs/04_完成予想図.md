## 1. 完成時の姿（全体像）
- アプリを開くと、その瞬間に「今日あと何をやればいいか」が全ゲーム分、一画面で分かる
- ゲームごとにリセット時刻が違っても、表示も通知もウィジェットも同じ「ゲーム日」で揃っている
- チェックする操作はタップ1回だけ。記録は自動で残り、ストリークと達成率で継続が見える
- リセット前には、残っているゲームだけ通知が来る

## 2. 画面構成
タブは3つ：**今日 / 統計 / 設定**。ゲームの管理は「今日」画面から各ゲームの詳細へ進んで行う。

### 2.1 今日（ホーム）

- 案B（オーロラ・グラス）を土台に、案Aのゲーム別カラーを組み合わせる。背景にはオーロラのグラデーションを使い、カードにガラス感の奥行きを持たせ、大きな残り件数の数字を視覚の主役にする。
- ライト／ダークモードでレイアウトを共通にする。ライトは淡いオーロラと白ガラス、ダークは深い背景とオーロラのグロー、半透明ガラスを使う。
- ゲーム色は判別用のドット、残り件数の数字、ほのかなグローに使う。カードの面は各外観モードのガラス表現で統一する。
- ゲームごとに用意された10色のパレットからテーマカラーを選び、パレット番号（インデックス）を保存する。新規ゲームには既存ゲーム数に応じてパレット順のデフォルト色を提案し、ユーザーは保存前に変更できる。
- パレットの各色は、ライト用の濃いめの色とダーク用の明るめの色を、同じ色相のペアで定義する。

```text
┌─────────────────────────────┐
│ 11月17日(火)      残り合計 5件 │
├─────────────────────────────┤
│ ゲームA        リセットまで 3:12 │
│ ☑ ログイン                     │
│ ☐ デイリークエスト 3つ          │
│ ☐ 週間ボス                     │
│   連続 12日 🔥                  │
├─────────────────────────────┤
│ ゲームB        リセットまで 8:40 │
│ ☐ ログイン                     │
│ ☐ デイリー素材集め              │
├─────────────────────────────┤
│ ✓ ゲームC（全て完了）           │
├─────────────────────────────┤
│ ＋ ゲームを追加                 │
└─────────────────────────────┘
```
- 残りがあるゲームを上に、全完了のゲームは畳んで下に
- 各ゲームの見出し：名前、リセットまでの残り時間、残り件数
- デイリーとウィークリーは見出しやラベルで区別できるように並べる

### 2.4 設定
- 通知：オン／オフ、リードタイム（15分／30分／60分／120分から選択）
- 通知権限の状態表示と案内

## 3. 操作の流れ（完成時にできること）
1. ゲームを登録する（名前とリセット時刻を入れる）
2. そのゲームのデイリー／ウィークリータスクを登録する
3. 毎日、遊び終わったタスクからチェックしていく
4. リセットを跨ぐと自動で新しい1日分になる
5. うっかり残していると、リセット前に通知が来る
6. 週末に統計で達成率を眺める

## 4. デザイン方針
- 標準のSwiftUIコンポーネントを基本とし、片手で素早くチェックできることを優先する
- 色は達成状態（完了／未完了／一部）の区別に使う。今日画面のゲーム別カラーと装飾は §2.1 の方針に従う
- ダークモード対応（システム設定に従う）
- 文字サイズはDynamic Typeに従う
