# AIへの依頼テンプレート

開発規約§6に基づく、AIへ依頼するときのひな形。コピーして、`` の部分を埋めて使う。
依頼のときは、`docs/` の文書（01〜04）と、対象のソースファイルを、AIへ渡す。

```text

ゲームのデイリータスク管理アプリ（iOS / SwiftUI / SwiftData）。仕様は docs/ を参照。仕様にないことを、AIの判断だけで追加しない。

























必要な箇所だけ変更し、無関係なコードは変更しないこと。
コードのコメントは日本語で書くこと。既存のコメントは、変更しない部分では消さずに残し、処理を変更した部分は、コメントも合わせて更新すること。
変更後は、規約§13の「AI変更報告」の形式で、変更ファイル・変更内容・影響を報告すること。
```

## AIが出したコードの扱い

AIが生成したコードは「未検証」であり、正式コードではない（規約§4.2）。
コード検証、シミュレーター、実機確認を経て、本人が正式採用してから `main` に統合する。
